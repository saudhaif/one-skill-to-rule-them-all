## ⚙️ ملاحظات التطبيق (لـ Claude عند الطلب)

- هذه روابط محفوظة كما وردت، ولم يُتحقق من محتواها أو أوامر تثبيتها بعد.
- عند طلب التثبيت: اقرأ ملف README في كل مستودع أولًا، واعرض على المستخدم ما يفعله أمر التثبيت والصلاحيات التي يطلبها، ولا تشغّل أي سكربت قبل موافقته.
- `claude-code-setup` من المستودع الرسمي `anthropics/claude-plugins-official`؛ البقية مستودعات طرف ثالث.
- Strix أداة اختبار أمني: لا تُستخدم إلا على أنظمة يملكها المستخدم أو مخوَّل باختبارها.
- FreeLLMAPI: راجع شروط مقدّمي النماذج قبل استخدام أي وسيط "مجاني" لواجهات النماذج، ولا تضع فيه مفاتيح API أو بيانات حساسة دون فهم أين تُرسل.
- ثبّت إضافة واحدة في كل مرة وتأكد من عملها قبل الانتقال للتالية.
