## 🧠 What You'll Learn (ماذا ستتعلم)

كيف تقوم بإنشاء **website** كامل واحترافي باستخدام **one line of code** فقط، من خلال استخدام أدوات مثل **Claude Code** و **Framer Motion** مع فهم أساسي في **UI/UX**.

## 🛠️ Tools You'll Need (الأدوات التي تحتاجها)

- **Claude Code** – لتوليد كود الموقع باستخدام **single line**
- **Framer Motion** – لإضافة **animations** و **smooth transitions**
- **UI/UX Skills** – لضمان تصميم احترافي وتجربة مستخدم ممتازة
- **21st dot dev** – لنسخ سطر الكود المطلوب واستخدامه داخل **Claude Code**

## 🧭 Step-by-Step Instructions (خطوة بخطوة)

### Step 1: Install Claude Code
- قم بتثبيت **Claude Code** على جهازك
- ادخل على الرابط الخاص به و انسخ **line of code**
- ثم الصقه داخل الـ **terminal** لبدء العملية

### Step 2: Install Framer Motion
- قم بتثبيت **Framer Motion**
- لإضافة **animations** احترافية و **interactive elements**
- حتى يظهر الموقع بشكل سلس وجذاب

### Step 3: Add UI/UX Skills
- قم بإضافة أو تحميل **UI/UX skill**
- حتى يفهم النظام أساسيات التصميم
- و يقوم بإنشاء **clean design** مع **proper structure**

### Step 4: Integrate with 21st dot dev
- ادخل إلى **21st dot dev**
- وانسخ **required line of code**
- ثم الصقه داخل **Claude Code**

وسيتم توليد **complete website** يحتوي على:
- تصميم نظيف (clean design)
- **smooth animations**
- **structured layout**

## ⚙️ ملاحظات التطبيق (لـ Claude عند الطلب)

- "السطر الواحد" هو أمر تثبيت أو prompt جاهز، وليس شيئًا يبني الموقع وحده؛ العمل الفعلي يكتبه Claude Code.
- التقنية المقترحة: React + Framer Motion (`npm install framer-motion`)، مع مكوّنات بأسلوب 21st.dev (مكتبة مكوّنات React/Tailwind).
- مهارة UI/UX: استخدم مهارة `ui-ux-pro-max` إن كانت متاحة.
- قبل البناء اسأل المستخدم: نوع الموقع (بورتفوليو، صفحة شركة، صفحة منتج…)، المحتوى، الألوان/الهوية، واللغة (عربي RTL أو إنجليزي).
- إن كان موقع `21st.dev` محجوبًا بسياسة الشبكة، ابنِ المكوّنات مباشرة بدلًا من نسخها.
- المخرجات المطلوبة: تصميم نظيف، حركات سلسة، تخطيط منظّم، ويعمل على الجوال.
