# Laces It

A phone-style web app for cycling and running crews in the UAE: rides with
Garmin (GPX) routes and sign-ups, a market for gear, and a crew ranking, in
Arabic, English, Filipino and Hindi.

- `laces-it.html` — the current app, published at
  https://claude.ai/artifact/4HJev2ajB5nrLajaq4Lru8
- `laces-it-data/` — the demo rides and listings the app holds.
- `yalla-crew.html` — the earlier version under the name Yalla Crew, kept for
  reference (https://claude.ai/artifact/JpB2p9Jcy2iFszBixE8Jq9).
